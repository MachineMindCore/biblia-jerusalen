# Biblia de Jerusalén

Biblia Católica completa — 73 libros, 35,548 versículos, diccionario bíblico con 952 términos.

## Características

- 📖 **73 libros** (Antiguo y Nuevo Testamento, incluyendo deuterocanónicos)
- 🔍 **Búsqueda** full-text en todos los versículos
- 📚 **Diccionario** bíblico con 952 términos
- ⭐ **Favoritos** y 📝 **Notas** personales
- 🌙 **Modo oscuro** para lectura nocturna
- 🌅 **Versículo del día**
- 📱 **PWA** — funciona offline, instalable en cualquier dispositivo
- 📦 **APK** para Android 5.0+

## Instalación

### Como PWA
Abre `index.html` en cualquier navegador o sirve la carpeta con un servidor HTTP.

### Como APK
Descarga el APK desde [Releases](https://github.com/morluto/biblia-jerusalen/releases).

## Tecnología

HTML + CSS + JavaScript vanilla. Zero dependencias externas. 100% offline.
